# Meeting Scribe EN 純英文會議筆記（english 分支）

**純英文會議**專用版，自 `meeting-scribe-v0.4.1` 分支。Deepgram 英文專用模型（`language=en`）＋講者分離，每句輸出繁中譯文；含主線移植的句子聚合器低延遲與麥克風混音。可與主線版本並存安裝（API Key 需分別填寫）。

## 安裝（開發模式）

### Chrome

1. `chrome://extensions` → 開發人員模式 → 載入未封裝項目 → 選這個資料夾
2. 點外掛圖示填入 API Key：Deepgram（必填）＋ DeepL 或 Gemini（擇一，翻譯引擎下拉選）
3. 到會議 / 影片分頁按「開始記錄這個分頁」

### Edge

Edge 為 Chromium 內核，本外掛可直接使用、無需修改程式碼：

1. `edge://extensions` → 左下角開啟「開發人員模式」→「載入解壓縮」→ 選這個資料夾
2. API Key 需在 Edge 中重新填一次（`chrome.storage` 不跨瀏覽器共用），填法與 Chrome 相同
3. 建議把會議分頁釘選，或到「設定 → 系統與效能」把會議網站加入「永不讓這些網站進入睡眠」清單——Edge 的睡眠索引標籤比 Chrome 積極，避免長時間會議在背景被節流

## 功能

- **多講者**：Deepgram `diarize=true`，自動標 Speaker A/B/C（chip 各配固定色）
- **中英夾雜**：`language=multi`（nova-3 code-switching）
- **雙語譯文**：每句輸出繁中＋英文；DeepL 模式依原文主語言只翻缺的方向省額度，Gemini 模式單次回傳雙語
- **講者命名**：面板「講者」按鈕展開名單，輸入姓名即時套用到歷史與匯出
- **會議錄音（v0.4.0）**：擷取的同時即時編碼 MP3（40kbps 單聲道，約 18MB/小時），按「音檔」立即下載、不用等轉檔；錄音在後台並行編碼，不增加翻譯延遲
- **接續 / 重新開始（v0.4.0 起涵蓋全部狀態）**：文字紀錄、講者對應、錄音三者同進退。換網址後開始記錄自動全部重置；同一頁再次開始會詢問「接續」或「重新開始」
- **匯出**：原文 / 中文 / 英文（.txt，含時間戳與講者名）＋ Markdown 會議記錄 ＋ MP3 錄音
- 沿用：可拖曳面板、捲動歷史、interim 動態原文、50% 透明

## 已知限制

- tabCapture 只收「分頁播出」的聲音＝遠端與會者；**你自己對麥克風說的話不會被記錄**（麥克風混音為未來選配功能）
- diarize 的講者編號在長時間靜音後偶爾會重排；發現接錯人時用講者命名功能校正
- Netflix 等 DRM 網站與 `chrome://` 頁面無法擷取
- 錄音存在記憶體中：外掛重載或瀏覽器重啟會遺失尚未下載的錄音，長會議建議中途按「音檔」先存一份（存檔後會繼續錄，之後再存仍包含全程）
- 會議中多次存檔的 MP3 為多段流串接，一般播放器都能正常播放，但少數播放器的總時長顯示可能不準
