# Caption Scribe 字幕同步翻譯（DOM 版）

目前版本：**v1.9.1**（Manifest V3，Chrome / Edge 共用同一套檔案）

直接擷取會議平台顯示在頁面上的即時字幕（DOM capture），把每句翻成繁體中文，
在半透明浮動面板上即時顯示，並可匯出逐字稿；也可選擇同時錄音並下載 MP3。

- 字幕來源：Teams / Webex / Google Meet 自動偵測，其他網站可手動框選字幕區域
- 翻譯引擎：DeepL 或 Gemini，也可關閉翻譯、只記錄原文（免 API Key）
- 開會時可直接在面板上修正辨識錯的字幕、改講者名，或先標記待會後再改
- 不會自己辨識語音：字幕內容來自平台，畫面上要有字幕才抓得到

本專案衍生自 **meeting-scribe-english-extension**，沿用其面板、翻譯與錄音架構，
但字幕來源從語音辨識改為 DOM。

## 安裝（開發模式）

1. 開啟 `chrome://extensions`（Edge：`edge://extensions`），打開「開發人員模式」
2. 按「載入未封裝項目」，選這個資料夾
3. 點外掛圖示，在「翻譯設定」選引擎並填 API Key（不翻譯則免填）

| 引擎 | 需要的 Key | 說明 |
|---|---|---|
| DeepL | DeepL API Key | Key 結尾是 `:fx` 時走 Free 端點，否則走 Pro 端點 |
| Gemini | Gemini API Key | 模型失效時自動換備援模型；失敗且有填 DeepL Key 時改用 DeepL |

## 使用

1. 在會議中開啟平台內建的「即時字幕 / Live captions」
2. 點外掛圖示。此時才會把面板注入頁面，狀態為「未擷取」
3. 依需要勾選「啟用翻譯」、「錄音」、「連同我的麥克風」，再按「開始擷取這個分頁的字幕」
4. 字幕開始出現在面板上；要結束時再點外掛圖示，按「停止擷取」
5. 用面板上的按鈕匯出；開新會議前建議按「清除」（見[已知限制](#已知限制)）

v1.7.4 / v1.7.5 起，開啟會議頁面時不會自動注入面板，也不會自動開始擷取，一律由使用者手動啟動。

非內建支援的網站要先按 popup 的「框選字幕區域」，再點選字幕所在的區塊（Esc 取消）。

### 面板

原文先顯示，譯文隨後補入同一條目。進行中的句子放在底部的即時區，
定稿後才移入歷史區，因此逐字修正時歷史列表不會跳動。半透明的文字表示還可能變動。

面板可拖曳。標題列的紅色呼吸燈表示**正在擷取字幕**，並不代表正在錄音。

| 按鈕 | 作用 |
|---|---|
| ⚑ n | 有標記「待修正」的句子時才出現；按一下只顯示待修正，再按一次顯示全部 |
| 原文 | 下載原文逐字稿 `caption-source-<時間>.txt` |
| 中文 | 下載譯文逐字稿 `caption-zh-<時間>.txt` |
| MD | 下載 Markdown 會議記錄 `caption-notes-<時間>.md`（原文＋譯文） |
| 音檔 | 下載錄音 `caption-audio-<時間>.mp3`。一律顯示：錄音中前面有紅點，沒有錄音時變淡 |
| 清除 | 確認後清除文字記錄、錄音，以及所有修改與講者改名 |
| − | 最小化，點最小化 icon 還原（外觀見下方） |
| ✕ | 只隱藏面板，擷取照常進行；用 popup 的「重新顯示字幕面板」叫回，位置會重置 |

最小化 icon 有兩種外觀，可在 popup 切換，已開啟的面板會即時套用：

- **隱密小標籤（預設）**：畫面右緣只露出 8px 的灰色半透明細條，沒有動畫。
  細條上有一個極小的狀態點，擷取中為淡紅色、未擷取為灰色。滑鼠移過去會滑出並顯示「‹」，點一下還原面板
- **機器人頭**：右下角的機器人 icon，擷取中睜眼、未擷取時睡覺，有動畫

### 即時修改字幕

辨識錯的字幕可以邊開會邊改。匯出檔一律使用修改後的內容。

- **修改一句**：滑鼠移到句子上按 ✎，或在文字上按兩下。原文和譯文各有一個編輯框
  - Enter 儲存、Esc 取消、Tab 切換原文／譯文、Alt+↑ / Alt+↓ 存檔並移到上一句／下一句
  - 只改原文：譯文會依修改後的原文自動重翻（翻譯開啟時）
  - 改了譯文：以你寫的譯文為準，不再自動翻譯
  - 只有已移到歷史區（停止變動）的句子能改；還在逐字變動的句子要等定稿
- **鎖定**：改過的句子會鎖定，平台之後對這句的更新不會蓋掉你的修改，而是顯示「平台有新版本」。
  滑鼠停在上面可看平台的新內容，點一下改用平台版本（會捨棄你的修改）
- **還原**：改過的句子會出現 ↺，點一下還原成平台原始字幕
- **改講者名**：點講者標籤直接改名，Enter 儲存、Esc 取消。有名字的講者會連同所有句子一起改（之後的新句子也是）；
  顯示「字幕」的句子只改那一句。清空名稱即還原
- **標記待修正**：來不及改時按 ⚑ 先標記，會後用標題列的「⚑ n」只顯示待修正的句子逐一處理
- **快捷鍵**（Mac 為 Option+Shift，可在 `chrome://extensions/shortcuts` 修改）
  - Alt+Shift+E：修改最新一句已定稿的字幕（面板隱藏時會自動叫出）
  - Alt+Shift+F：標記／取消最新一句為待修正
- **不會誤觸平台快捷鍵**：在編輯框打字時，按鍵不會傳到會議頁面；中文輸入法選字時按 Enter 不會誤存

原始字幕一律保留，修改另外存在修改表（`cs_edits`）與講者對照表（`cs_spkMap`），顯示與匯出時才合併。

### Popup 選項

| 選項 | 說明 | 預設 |
|---|---|---|
| 啟用翻譯 | 關閉時只記錄原文，不呼叫任何翻譯 API | 開 |
| 錄音 | 錄下分頁聲音；擷取中勾選會立即開始，取消勾選會停止（已錄的部分保留） | 關 |
| 下載錄音（MP3） | 隨時下載目前為止的錄音，不需要字幕面板；會議分頁已關閉也能下載 | — |
| 連同我的麥克風 | 把自己的發言混音錄入，勾選時會自動勾「錄音」；首次使用會開分頁要求授權 | 關 |
| 最小化時用隱密小標籤 | 關閉則改用機器人頭 | 開 |
| MD 匯出時標出修改前的原文 | 改過的句子在 MD 裡多一行刪除線標出平台原文 | 關 |
| 混雜句英文 ≤ 2 個單字時不翻譯 | 省翻譯額度 | 開 |
| 框選字幕區域 / 清除框選 | 為目前網站指定字幕區塊，或還原成內建偵測 | — |
| 匯出字幕結構 | 除錯用，下載字幕區塊的 HTML，平台改版要調整解析規則時使用 | — |

## 翻譯規則

只輸出繁體中文，不做中翻英。

| 原文 | 處理方式 | 呼叫 API |
|---|---|---|
| 純中文 | 原樣顯示 | 否 |
| 純英文 | 整句翻成繁中 | 是 |
| 中英夾雜，英文 ≤ 2 個單字 | 原樣顯示（可在 popup 關閉此行為） | 否 |
| 中英夾雜，英文 > 2 個單字 | 中文保留，只翻英文部分 | 是 |

DeepL 把英文片段抽出來逐段翻譯後拼回原句，並以整句作為上下文；
Gemini 則透過 prompt 要求保留中文部分。

## 錄音

- 預設只錄分頁聲音（遠端與會者）；勾選麥克風後才會混入自己的聲音。
  麥克風開啟迴音消除，戴耳機效果最好，無法取得麥克風時降級為只錄分頁聲音
- 格式為 40 kbps 單聲道 MP3，約 18 MB／小時
- 可隨時從面板的「音檔」或 popup 的「下載錄音」存檔；錄音中存檔不會中斷，之後再存仍包含全程
- popup 會顯示錄音狀態：錄音中、已停止（可下載）、尚無錄音
- 會議分頁關閉或擷取中止時，錄音自動停止，已錄的部分保留，可從 popup 下載
- 停止後再開始會接續同一段錄音，按「清除」才會重置

## 運作原理

```text
字幕 DOM ──MutationObserver／定時掃描──> content.js ──TRANSLATE──> background.js ──> DeepL / Gemini
                                            │  譯文補回同一條目
                                            └──> 面板顯示、chrome.storage.local、匯出

popup.js ──START_REC──> background.js（取 tabCapture streamId）
                            └──> offscreen.js（分頁聲音＋麥克風）──> worklet.js（PCM）──> lamejs（MP3）
```

- **字幕來源選擇**：有框選就優先用框選；但若框選解析不到講者、內建偵測解析得到，會自動改用內建結果。
  面板狀態列會顯示目前的來源、講者解析結果與已擷取句數
- **講者名稱**：優先用平台標記；解析不到時依區塊結構、名字與內容成對的區塊、
  「名字: 內容」前綴依序判斷，都失敗才顯示「字幕」
- **去重**：同一節點就地更新；Teams 重建 DOM 時，到最近 12 條記錄比對，
  完全相同或相似度 ≥ 0.85 視為同一句（短句不跨條合併，重複說的話會保留）
- **預先翻譯**：字幕變動中就先翻（每條最快每秒一次），先顯示半透明的暫定譯文
- **定稿**：文字閒置 1.8 秒後定稿；若最後一次譯文已對應最終文字就不再重翻。
  定稿後字幕又變長時會回到未定稿狀態並重翻
- **Gemini 穩定性**：請求排隊並間隔 1.2 秒；429／5xx 重試一次，404 換下一個模型

### 檔案

| 檔案 | 職責 |
|---|---|
| `manifest.json` | MV3 設定；不宣告 `content_scripts`，由 popup 注入 |
| `popup.html` / `popup.js` | 設定介面、注入內容腳本、開始與停止 |
| `content.js` / `content.css` | 字幕解析、去重、面板、即時修改、匯出、框選 |
| `background.js` | 翻譯服務、錄音流程控制、快捷鍵轉送 |
| `offscreen.html` / `offscreen.js` | 在 offscreen document 擷取音訊並編碼 MP3 |
| `worklet.js` | AudioWorklet：混單聲道並轉 16-bit PCM |
| `lame.min.js` | lamejs MP3 編碼器 |
| `mic-permission.html` / `mic-permission.js` | 麥克風授權頁（offscreen 無法跳出權限詢問） |

## 隱私與資料

- API Key、設定、框選位置與字幕記錄都以明文存在瀏覽器本機（`chrome.storage.local`），不會自動刪除
- 啟用翻譯時，需要翻譯的字幕內容會送到所選的服務（DeepL 或 Google）；關閉翻譯則不會外傳
- 錄音只存在記憶體，由使用者手動下載
- 錄音與記錄會議內容前，請先確認符合公司規定、當地法規，並取得與會者同意

## 已知限制

- 擷取品質取決於平台字幕；對方或自己沒開字幕就沒有來源
- 平台改版可能使自動偵測失效，可改用「框選字幕區域」；框選位置也可能因版面變動而失效
- 分頁重整後要再按一次「開始擷取」
- **字幕記錄是全域共用的**，不分分頁或網站：新會議會接在舊記錄後面，同時在多個分頁擷取會互相覆蓋。
  開新會議前請先按「清除」
- 錄音存在記憶體，外掛重載或瀏覽器重啟就會遺失；長會議建議中途先存一份
- 翻譯失敗的訊息（例如「(翻譯失敗 403)」）會寫入譯文欄並出現在匯出檔，該句不會再自動重試；可用 ✎ 修改原文觸發重翻，或直接改譯文
- 關閉翻譯時，「中文」匯出檔只有時間與講者，沒有內容
- 翻譯規則以中英文為設計對象；含漢字的日文會被視為中文而不翻譯
